Natours

Natours is a comprehensive tour booking web application built using the MERN stack (without React), featuring Node.js, Express, MongoDB, and Pug for server-side rendering. The platform enables users to explore and book eco-tours through an interactive Mapbox-powered map interface. It includes Stripe integration for secure payments, JWT-based authentication, role-based access control, and AWS S3 for image uploads with proper CORS configuration. To enhance user engagement and account security, SendGrid is integrated for transactional email services, including welcome emails on signup and password reset flows. Both admins and users have access to dynamic chart and table visualizations for actionable insights. Admins also have full CRUD capabilities over users, tours, reviews, and bookings. The app is built with a clean MVC architecture and features a polished, responsive UI.

Netflix And Chill

A full-stack streaming platform inspired by Netflix, built with React and Spring Boot. Users can browse and search for movies, watch trailers, and manage a personalized favorites list. The application includes a responsive, modern UI with dynamic routing and real-time data updates using Redux and Axios. As an admin, you can manage users, oversee the community board, reply to user comments, and update content seamlessly through the dashboard. The app is fully Dockerized and connected to a MySQL backend, with media and API services deployed on the cloud.

Wetube

A full-stack video streaming platform inspired by YouTube, developed using Node.js, Express, MongoDB, and Pug for server-side rendering. It replicates core YouTube functionalities such as video browsing, playback, uploading, and user interaction. Users can upload their own recordings via Multer, with secure file storage managed through AWS S3. The app also features GitHub OAuth for authentication, real-time commenting, and a responsive UI for a dynamic user experience. This project highlights strong backend architecture, secure media handling, and integration of third-party services.

Forkify Recipes

A dynamic and interactive recipe search app built entirely with vanilla JavaScript, HTML, and CSS. The Forkify app allows users to search for recipes from a third-party API, view detailed ingredients and instructions, adjust serving sizes with real-time updates, and bookmark favorite meals for quick access. Designed with modular architecture, it showcases clean code practices, responsive layout, and a seamless user experience without relying on frameworks. Ideal for demonstrating mastery of core JavaScript concepts, API integration, and client-side state management.
